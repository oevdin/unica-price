# Калькулятор дверей Терем

Веб-программа для расчёта межкомнатных дверей Терем по дилерскому прайсу и выпуска документа
«Эскиз и предварительный расчёт» для клиента.

Прайс-лист Терем от **17.08.2026**, редакция 1.

## Как открыть

Откройте `index.html` в браузере (Chrome, Safari, Edge, Firefox). Интернет нужен только для шрифтов
и кнопки «Скачать PDF». Файлы `instruction.mp4` и `instruction.webm` должны лежать рядом с `index.html`:
их показывает кнопка **«Инструкция»** в шапке программы.

## Что умеет

- Цены полотен по всем коллекциям прайса, наценки за высоту и ширину, категории цвета, стекло.
- Обязательный стабилизатор для полотен выше 2350 мм.
- Автоподбор погонажа: система L / Q / RQ / M, наличник, добор по толщине стены, длина 2120–3000 мм с наценкой.
- Рисунки моделей из прайса на эскизе с размерами.
- Несколько дверей в одном расчёте, свои строки (фурнитура, доставка, монтаж), наценка и скидка.
- Документ для клиента без валюты, выгрузка в PDF, история расчётов.
- Светлая и тёмная тема, работа на телефоне.

## Структура

| Путь | Что это |
|---|---|
| `index.html` | Готовая программа (собрана из `src/`) |
| `instruction.mp4`, `instruction.webm` | Видео-инструкция с озвучкой |
| `src/app_src.html` | Интерфейс и логика расчёта |
| `src/data.json` | Цены из прайса: коллекции, покрытия, стекло, погонаж, наценки за габариты |
| `src/imgs.json` | Рисунки моделей из прайса с подписями |
| `src/extract.py`, `src/data.py` | Извлечение цен из прайса `.xlsx` → `data.json` |
| `src/imgs.py`, `src/crop_models.py` | Вырезка рисунков моделей из прайса → `imgs.json` |
| `src/build.py` | Сборка `index.html` |
| `video/` | Сценарий, озвучка и запись видео-инструкции |

## Обновление на новый прайс

```bash
cd src
mkdir -p price && cp /путь/к/новому/прайсу.xlsx price/
unzip -q price/*.xlsx -d price/unzipped
python3 extract.py      # таблицы цен → raw.json
python3 data.py         # → data.json (поправьте priceDate и priceVer)
python3 imgs.py         # рисунки моделей → imgs.json
python3 build.py ../index.html
```

После обновления проверьте расчёт на 2–3 знакомых дверях и сверьте с листом «Комплекты» прайса.

## Пересборка видео

```bash
cd video
pip install piper-tts playwright
python3 tts.py          # озвучка → vo/
python3 rec.py          # запись экрана → raw.webm, marks.json
python3 mix.py          # → instruction.mp4
```
